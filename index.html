🔑 Change Passwords

The Reviewer password is stored in browser storage — share it verbally with staff. The Admin password must also match the ADMIN_PASSWORD environment variable set in Netlify (Site Settings → Environment Variables) — otherwise server data won't load. Update both together.

⚙️ The Admin password is set via the ADMIN_PASSWORD environment variable in Netlify and cannot be changed here. Contact your Netlify admin to update it.
